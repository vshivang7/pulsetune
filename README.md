# 🎶 PulseTune  

Live Demo → [pulsetune-ayn4.onrender.com](https://pulsetune-ayn4.onrender.com)  

PulseTune is a full-stack music web application that lets users explore, stream, and organize music playlists seamlessly.  

---

## ✨ Features  

### For Users  
- 🔐 Secure login & signup with **Passport Auth**  
- 🎵 Search and explore songs & artists via **Spotify NoCodeAPI**  
- 📂 Create, edit, and manage playlists  
- ▶️ Music player with **play, pause, skip, queue, and history tracking**  
- 📱 Responsive and modern UI for smooth experience  

### For Admins *(future scope)*  
- Manage authentication and users  
- Control API integration for music data  

---

## 🛠 Tech Stack  
- **Frontend:** React.js, Tailwind CSS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Authentication:** Passport.js (with hashed passwords)  
- **APIs:** Spotify NoCodeAPI
